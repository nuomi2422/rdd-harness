**装在哪**：`D:\rdd\tools\mcp-memory\`（pnpm 装的 `@modelcontextprotocol/server-memory`）。


- **库文件跟 rdd-docs 仓走**，能被 git 备份；路径由 `start-memory-mcp.mjs` 解析（支持 `RDD_ROOT` 覆盖）。

## 7 · 常见故障 → 处置

| 现象 | 先查（按顺序） | 处置 |
|---|---|---|
| 同伴不动 / 周期 `loop_detected` / `ai.jsonl` tools 数不变 | **① 网络/provider ② 余额 ③ 才看代码** | 查日志有无 401/402/5xx；恢复网络别急着改代码 |
| `primary_waiting: dependency assets not present` 长期 | 该级 `waitFor` | 查是否被误加硬门（RL-2/RL-3） |
| 监测台没数据 | `NUMEN_MONITOR_DIR` | 用正确实例目录重启 server |
| 游戏起不来 | `logs\latest.log` + `rdd-launch-*.log` | 看是否 mod 冲突（`ResolutionException`）/ 启动参数重复 |
| 相机不跟拍 | `/cam status` 的 `target=` 后有没有「（渲染范围内）」 | 没匹配上 = 名字写错（**不报错，静默退回第一人称**） |
| 附身后视角没切 | `/cam status` 的「附身」行 | 目标必须已召唤且在本存档；联机服需 OP |
| `.ps1` 报语法错 / 中文乱码 | 是否含中文注释 | **含中文必须存 UTF-8 BOM**（PS 5.1 把无 BOM UTF-8 当 ANSI 读） |
| MCP 连不上 8765 | MC 是否在跑 / `mcp_server.json` 的 `enabled` | 起 MC 或改 config |
| 磁盘被 `numen\` 吃满 | `monitor\context-*.jsonl` 堆积 | 跑 `cleanup-logs.ps1`（见 16 号文） |
| 远端连不上（内存打满） | 先跑 `rescue-remote.ps1`（只报告） | 见 14 号文 §救火开关；**绝不碰 opencode 本体** |
